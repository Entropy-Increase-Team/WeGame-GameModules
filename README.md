# WeGame-GameModules

这里对应模块总仓库的 `main` 分支占位目录。

约定如下：

- 总仓库：`https://github.com/Entropy-Increase-Team/WeGame-GameModules`
- 默认分支：`main`
- `main` 分支仅保留说明文件
- 各游戏模块使用独立分支维护
- 分支名与模块名一致，例如 `rocom` 模块对应 `rocom` 分支

## 手动拉取命令


### 1. 洛克王国：世界

```bash
git clone -b rocom --single-branch https://github.com/Entropy-Increase-Team/WeGame-GameModules.git plugins/WeGame-plugin/modules/rocom
```
